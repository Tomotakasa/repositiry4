# NAS Photo Album Selector

NASサーバーの写真を自動的に選別して、アルバム用フォルダを作成するWebアプリです。

## 機能

- **NAS接続**: SMB/CIFS・SFTP・ローカルマウントパスに対応
- **フォルダ選択**: NASのフォルダをブラウザで複数選択
- **期間フィルタ**: 撮影日の範囲を指定
- **AI選別**: Claude AIが写真を評価・ランキング
- **アルバムタイプ**: 9種類のテーマ + カスタム指定
- **枚数指定**: 5〜200枚の範囲で選択数を指定
- **ローカル品質フィルタ**: ぼけ・重複・露出不良をAIより前に除去（API消費を最小化）
- **自動保存**: 選別した写真をNASのアルバムフォルダにコピー

## API消費の最小化

1. **ローカル前処理**: ぼけ検出・重複除去をPilのみで実施（API不使用）
2. **候補絞り込み**: 選別枚数×3枚に絞ってからAIに送付
3. **バッチ処理**: 1回のAPI呼び出しで8枚を評価（呼び出し回数を削減）
4. **小サイズ**: 400×400pxのサムネイルを送付（トークン数を削減）
5. **安価なモデル**: `claude-haiku-4-5`を使用（最も低コスト）
6. **スコアキャッシュ**: 同じ写真の再評価を回避

## セットアップ

### 1. 環境変数の設定

```bash
cp .env.example .env
# .env を編集して ANTHROPIC_API_KEY を設定
```

### 2. Docker で起動（推奨）

```bash
docker-compose up --build
```

### 3. ローカルで起動

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

ブラウザで http://localhost:8000 を開く

## NAS接続タイプ

| タイプ | 用途 | 必要な情報 |
|--------|------|-----------|
| SMB/CIFS | Synology・QNAP・Windowsファイル共有 | ホスト・共有名・ユーザー名・パスワード |
| SFTP | SSH有効なNAS（Synology等） | ホスト・ユーザー名・パスワード |
| ローカルパス | マウント済みNAS・ローカルドライブ | マウントパス (`/mnt/nas` 等) |
