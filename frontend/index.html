✅
NASはローカルネットワーク内でOK

192.168.x.x などの プライベートIPでアクセス可能なNASがあればそのまま使えます。

✅
SMB / SFTP / ローカルパス すべて利用可能

同じLAN内なので接続方式を問いません。

起動手順

  1. ターミナルで以下を実行 
    cd backend
export ANTHROPIC_API_KEY="sk-ant-xxxx"
export APP_PASSWORD="あなたのパスワード"   # 省略すると認証なし
uvicorn main:app --host 0.0.0.0 --port 8000
  2. 同じPCのブラウザで開く 
    http://localhost:8000
  3. 他のPCやスマホから使う場合は、サーバーPCのIPを使う 
    http://192.168.x.x:8000
⚠️
NASをインターネットに公開する必要があります

ルーターでポート開放 (SMB: 445 または SFTP: 22) が必要です。セキュリティのため SFTPを推奨します。固定IPまたはDDNSドメインがあると便利です。

✅
バックエンドは Render.com (無料) で動かせます

Dockerfileが同梱済みなのでGitHubと連携するだけでデプロイできます。

Render.com デプロイ手順

  1. render.com に無料登録し、GitHub と連携
  2. New → Web Service からこのリポジトリを選択
  3. ダッシュボードの Environment タブで以下の環境変数を設定
    キー値
    APP_PASSWORDログインパスワード (任意の文字列)
    ANTHROPIC_API_KEYsk-ant-xxxxxxxx...
  4. Deploy → 完了後に表示されるURLでアクセス 
    https://your-app-name.onrender.com
💡 無料プランは15分間アクセスがないとスリープします。常時起動は $7/月 (Starter) プランに変更してください。
